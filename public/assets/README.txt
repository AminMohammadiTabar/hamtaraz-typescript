Optional local font dependency: B Lotus (BLOTUS.TTF).
Place the file exactly at public/assets/fonts/BLOTUS.TTF.
The application serves it from /assets/fonts/BLOTUS.TTF as font/ttf.
Check installation at http://localhost:8080/diagnostics/font.
See public/assets/fonts/README.md and scripts/check-font.ps1.
The font binary is not redistributed.
