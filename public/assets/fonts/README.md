# نصب فونت B Lotus

فایل مجاز `BLOTUS.TTF` را دقیقاً در همین پوشه قرار دهید:

`hamtaraz-typescript/public/assets/fonts/BLOTUS.TTF`

نکته‌ها:
- نام فایل باید دقیقاً `BLOTUS.TTF` باشد؛ در ویندوز گزینه نمایش پسوند فایل‌ها را فعال کنید تا نام واقعی `BLOTUS.TTF.ttf` نباشد.
- فایل باید یک فونت معتبر TrueType/OpenType باشد، نه ZIP یا فایل تغییرنام‌داده‌شده.
- پس از کپی فایل، صفحه را با `Ctrl + Shift + R` تازه‌سازی کنید.
- برای بررسی اینکه سرور فایل را می‌بیند، آدرس `http://localhost:8080/diagnostics/font` را باز کنید.
- اگر `available` برابر `true` و `validSfntSignature` برابر `true` باشد، فایل در مسیر درست و با امضای معتبر شناسایی شده است.
- فونت داخل مخزن توزیع نمی‌شود؛ مسئولیت رعایت مجوز استفاده با دارنده فایل است.
